## Frontend

- Check nearby components, hooks, translations, and utilities before adding new ones.
- Add user-facing text to both `src/messages/en.json` and `src/messages/fr.json`; use `Commons` for shared labels.
- Keep TypeScript types accurate; validate data at API and other trust boundaries.
- For behavior changes, add or update focused tests and run relevant checks.
- Make the smallest change that fully fixes the issue; avoid unnecessary dependencies and abstractions.
- Preserve responsive layouts, accessibility, and existing design conventions.
